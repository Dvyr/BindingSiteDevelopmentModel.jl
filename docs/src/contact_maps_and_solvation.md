# Definition of Chain Contacts in the Tetrahedral Lattice

The proposed protein folding model is based on a tetrahedral (diamond-cubic) lattice representation in which chain conformations are generated via a three-state bond-continuation rule. This formulation preserves a fixed tetrahedral valence angle (109.47°) while allowing discrete conformational flexibility through transitions among the eight body-diagonal bond orientations $\{\pm 1, \pm 1, \pm 1\}$.

Let a polymer of N monomers be represented by coordinates $\mathbf{r}_1, \mathbf{r}_2, \dots, \mathbf{r}_N$, connected by $N-1$ bond vectors $\mathbf{v}_k = \mathbf{r}_{k+1} - \mathbf{r}_k$. Non-bonded chain contacts are evaluated across all $N$ monomers according to the following rules:

1. **First Residue (\(k = 1\)):** The coordinates of the first residue are set arbitrarily to $\mathbf{r}_1 = [0, 0, 0]$. Exploiting the global rotational symmetry of the lattice, the first bond vector is fixed to $\mathbf{v}_1 = [1, 1, 1]$, placing residue 2 at $\mathbf{r}_2 = [1, 1, 1]$. Consequently, the remaining three nearest-neighbor lattice sites for residue 1, namely $[1, -1, -1], [-1, 1, -1], \,\text{and}\, [-1, -1, 1]$, serve as its potential non-bonded contact coordinates.
2. **Internal Residues $k \in \{2, \dots, N-1\}$**: Given the incoming bond vector $\mathbf{v}_{k-1}$, the three valid non-reversing continuation vectors from $\mathbf{r}_{k}$ are generated via the Hadamard (elementwise) product:  
   $\mathbf{u}_{k,i}=\mathbf{v}_{k-1}\odot \mathbf{t}_{i},\quad i\in \{1,2,3\}$  
   using the transformation vectors:  
   $\mathbf{t}_{1}=(1,1,-1),\quad \mathbf{t}_{2}=(1,-1,1),\quad \mathbf{t}_{3}=(-1,1,1).$  
   One of these three vectors is selected as the outgoing covalent bond $\mathbf{v}_{k}$ (placing residue $\mathbf{r}_{k+1} = \mathbf{r}_k + \mathbf{v}_k$, while the remaining two vectors define the **two** candidate non-bonded contact coordinates $\mathbf{r}_k + \mathbf{u}_{k,j} \,(j ≠ i)$.
3. **Terminal Residue (k = N):** Because residue $N$ has no outgoing covalent bond, all three vectors generated by $\mathbf{v}_{N-1} \odot \mathbf{t}_i \;\text{where: } i \in \{1, 2, 3\}$ define potential contact coordinates $\mathbf{r}_N + \mathbf{u}_{N,i}$.
